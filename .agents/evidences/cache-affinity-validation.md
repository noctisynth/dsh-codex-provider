# Codex 会话缓存亲和接入验证

编号：EVIDENCE-051。日期：2026-11-12。关联：RFC-002、SPEC-002、EVIDENCE-050、TODO-001。范围：功能阶段一的最小实现与离线验证，不含真实缓存收益或安装验收。

## 实现

- 复用已有 SHA-256 Base64URL body key，经最小内部访问器送达 HTTP 传输层，不另存 ID、不改编码和会话生命周期。
- 仅 Codex 浏览器与设备码 Responses 请求添加 `session-id`，取值与现有 body key 相同。头放在每个请求上，不污染共享客户端，SIWC 和无会话 ID 请求保持原样。
- 提取原生 Responses 请求构造方法，以便直接构建最终 reqwest Request 验证线协议；正式发送继续使用同一构造方法。未新增网络协议、设置、重试或诊断产品 API。

依据为 EVIDENCE-050 的固定正式版 Codex 缓存亲和契约；没有把公开 API 的路由说明等同于 ChatGPT 后端行为，也没有一起补没有收益依据的其他请求头。

## 验证

Rust 50 项单元测试通过，包含两条 Codex 登录和 SIWC 的最终 HTTP 请求构造验证：同 ID 稳定、新 ID 隔离、前后请求不串头、缺失或空 ID 省略、body 不泄露宿主字段、`store=false`、`stream=true`，以及不顺带添加 `x-client-request-id`。既有 key 测试继续覆盖恢复、模型或 effort 变化及长 ID。

Rust fmt 与全部目标、全部特性的 Clippy 通过。最初测试因局部 Option 类型未显式标注而编译失败，补充类型后重跑通过；未修改产品行为来绕过失败。

官方 napi-rs release 构建通过；正式 DSH LlmRuntime 的合成会话身份测试通过，覆盖序列化会话头恢复、重建适配器、新会话和无 ID 调用。该宿主测试以模拟流验证身份传递，最终 HTTP 头由上述 Rust 测试验证，不冒充真实端到端缓存测量。

构建先遇到外部 pnpm 启动器的临时目录权限与 wrapper 缺失，改用宿主提供的同版本 pnpm 11.28.5 入口；官方 napi-rs 在父目录创建 sibling staging 时另获单次权限后完成。未更改包管理器版本、项目配置、加载器或官方构建流程。
