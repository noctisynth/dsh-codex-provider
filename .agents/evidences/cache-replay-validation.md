# 无损输出重放修复验证

编号：EVIDENCE-052。日期：2026-11-12。关联：RFC-002、SPEC-002、EVIDENCE-050、TODO-001。范围：功能阶段二的最小实现和离线验证，不含真实模型、缓存率及安装验收。

## 最小实现与支持依据

- 保留原有按原生索引收集的集合，完成通知按同项身份与索引合并，不再以非空数组整体覆盖 done。保留已收到的非空加密资料，同一最终集合用于补完、回放及推理检查点输出摘要；可见终态或调用关联真正冲突时沿用协议错误，不新增重试或容错框架。
- 新格式 `dsh-codex-provider/responses-v2` 只保存一份有序原生 `items`，不在 UI 每块重复复制。正式 DSH ReplayEnvelope 允许省略逐块元数据，response 由宿主作为 opaque JSON 保留。
- 已核对宿主同 adapter 的正式替换和投影入口没有通用的正文一致性清除保证。因此使用现有 SHA-256／Base64URL 对固定可见字段 tuple 计算最小 `contentDigest`，写读共用同一函数，不计算 source、用量或时间，也不解析再重编码工具参数。
- 新消息读取摘要不符时，不用旧 raw 内容覆盖当前可见内容，不继承相应推理检查点。旧格式保留读取及空快照 fallback，不迁移历史，不伪造已经丢失的顺序或密文。
- `include` 显式请求加密推理，搜索开启时同时保留来源参数，不新增配置。参数声明与真实后端回传是否发生仍是不同验收层次。

完全没有可见内容块的整个 assistant 响应受 DSH 历史派生规则限制；不伪造块、不修改宿主。正常带可见内容的响应中，前、中、后的不可见原生项必须完整保留。

## 宿主回归

正式 BlockAssembler、AssistantStreamAccumulator、Session 的合成回归验证：UI 块首现顺序为工具、推理、文本时，响应级原生有序集合仍原样保留；序列化消息事件与会话头、重建 Session 后，LlmRuntime 与插件适配器继续透传同一 envelope 和原始工具参数。该测试的原生流被模拟，用于验证宿主 opaque 元数据契约，不冒充 Rust 输出解析或真实网络闭环。

该回归与既有会话身份测试通过；两侧 Oxc tsrs 与 Biome 通过。最初新测试缺少 MessageSource 的 assistant 类型收窄，补充准确类型判断后通过，未使用类型豁免。

Rust 56 项单元测试通过。新增聚合回归覆盖稀疏通知与密文补齐、同项去重、身份／索引／终态冲突、UI 与原生顺序相反、多段内容、不可见项及搜索引用、原始参数与 phase、JSON 恢复、所有可见字段编辑／调序／删块失效及固定 High 前缀一致。既有切档、账号／模型变化及旧格式回归继续通过。

旧格式没有原生历史摘要，读取时只复用其现存项目经既有 Mapper 可见投影后与当前内容一致的资料；否则按可见内容降级，不继承检查点。不恢复旧已丢失的全局顺序或载荷。显式空正文／摘要清除已闭合非空正文，以及调用名称或关联变化，均按实际协议冲突拒绝；不同非空加密最终值采用完成项，不解析 opaque 内容。

官方 napi-rs release 构建、npm 归档及正式加载器测试通过；完整 Node 套件 37 项（含子测试）、Rust 56 项、两侧 Oxc tsrs、Biome、Rust fmt 和全部目标／特性的 Clippy 均通过。打包验证同时覆盖根原生库与官方生成平台包解析，不代表其他三个系统已实际构建或安装。

已记录阶段二产品变更集，按授权本地提交。当前没有真实模型请求、真实凭据访问、安装、推送或发布；实际缓存收益和真实稀疏通知是否触发仍未验收。
