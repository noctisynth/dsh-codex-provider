# Legacy 额度与图片生成实测及接入

编号：EVIDENCE-037。日期：2026-11-07 至 2026-11-08。适用：现有 Codex legacy 凭据、DSH 0.2.2-rc.1、Windows x64。关联：RFC-001、SPEC-001、FACT-002、TODO-001。

## 来源与验证边界

用户授权为 legacy 接入额度与图片生成，仅在对应账号展示数据。参考社区插件 3.2.6 发布实现的请求格式，没有执行或安装社区代码。公开来源为[社区项目](https://github.com/WSL043/dsh-codex-subscription)。[SIWC 预览限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)仍作为 SIWC 范围依据；legacy 后台可用性来自实际请求，不将其视为一般公开 API 或 SIWC 权限保证。

只使用已有 legacy 记录和合成图片描述。诊断输出限制为 HTTP 状态、字段类型、计数与合成图片尺寸；不保存或输出令牌、原始用量响应、账号标识或实际套餐余额。凭据文件及活动账号在探测前后保持一致。

## 实际接口结果

- GET `https://chatgpt.com/backend-api/wham/usage` 返回 HTTP 200。响应具有 plan_type、rate_limit、credits 等字段；当前实际主窗口有效，次窗口、额外窗口和代码审查窗口可为空。仅投影套餐、窗口名称及长度、剩余比例、绝对重置时间和积分，排除服务返回的身份字段。
- POST `https://chatgpt.com/backend-api/codex/images/generations` 使用相同 legacy 账号请求头及插件身份，指定 gpt-image-2。两次合成生成分别经原始探测和最终 napi-rs 构建完成，得到有效 PNG，内容符合蓝色、绿色圆形的合成描述。没有使用 SIWC、API key、其它客户端凭据或静默跨路线回退。
- 所测接口返回尺寸为 1536×1024，与请求首选尺寸不一致。尺寸参数只表示首选，工具描述明确实际尺寸由服务决定；附件展示使用返回图片经宿主验证后的真实尺寸，不伪造请求尺寸。

实际结果仅代表所测账号、日期和接口，不保证所有套餐均有额度数据或生图授权。两种 legacy 登录共用账号格式、请求和能力定义；本次真实凭据为设备码路线，不重复授权浏览器路线。

## 实现与集成

Rust 分离额度、图片生成模块，共用传输认证、结构化错误和取消。额度不进入账号摘要轮询，指定账号的刷新保持凭据事务及活动账号不变。图片输出受宿主附件容量约束，Base64 仅在原生内部解码，PNG 交由正式 AttachmentStore 验证和保存。

两种 legacy 开放 quota、image_generation；SIWC 保持关闭。账号页仅为有额度能力且已登录的账号显示额度，提供显式刷新；查询失败清除旧数据并显示重试提示，不以本地计数推算。中英文字典复用已有 locale。生图工具的正式注册条件检查当前账号能力，使用当前 legacy 凭据，适用于 DSH 会话；切为 SIWC 后不纳入新步骤的声明与分发。没有新增开关、图片编辑、图库、余额修改或自动探测。

最终原生额度 RPC 成功返回有效窗口，账号选择及凭据保持一致，投影不含身份和令牌字段。最终原生生图通过 DSH 官方 NativeToolExecutor 执行并由安装包提取的正式 LocalAttachmentStore 保存。首次展示断言因验证脚本遗漏必填提示词参数而失败；使用同一张已生成图片及正确参数补验，未重复生图消费。正式工具执行器、附件重新读取、展示投影及持久元数据均通过，图片为 895514 字节、1536×1024。

模型输出只包含生成完成文字；图片引用保存在工具展示元数据中，经 presentResult 展示，未把图片 Base64 或图片块加入工具模型历史。公开内容块契约只允许用户消息携带图片，因此没有扩展或绕过已有对话图片投影。
