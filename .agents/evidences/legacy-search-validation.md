# Legacy 内置搜索实测与接入

编号：EVIDENCE-036。日期：2026-11-07。适用：当前 legacy 凭据、Codex Responses、DSH 0.2.2-rc.1、Windows x64。关联：RFC-001、SPEC-001、FACT-002、TODO-001。

## 授权与方法

用户要求调查并接入 legacy 搜索，尽可能复用现有链路。先用已有未过期 legacy token 验证当前 Codex Responses 的内置 web_search；只发送合成的 Rust 官方文档查询，不发送私人会话、不重登或切账号、不调用社区专用搜索或其它后台能力。

[官方搜索文档](https://developers.openai.com/api/docs/guides/tools-web-search)描述 web_search、强制工具选择、来源与引用；该文档不单独保证第三方 legacy 后台权限。实际支持结论来自本次接口和最终原生集成验证。

请求沿用当前 legacy 模型目录的兼容版本、账号请求头及插件 attribution。推理保持 store=false、stream=true，使用既有工具、tool_choice={type:web_search} 和 web_search_call.action.sources 参数，没有针对 legacy 添加请求参数或更换身份。

## 接口实测

同一 legacy token 的模型目录请求返回 HTTP 200。以下搜索均 HTTP 200、response.completed，存在非空回答、已完成 web_search_call 和 Rust 官方来源，不只凭请求成功判断可用。

| 请求 | 已完成搜索数 | 来源数 | URL 引用数 |
|---|---|---|---|
| Sol 内置搜索 | 1 | 23 | 1 |
| Sol 保留第一轮输出后的第二轮搜索 | 1 | 12 | 1 |
| Astra 内置搜索 | 1 | 28 | 1 |

探测前后凭据摘要一致，没有刷新、改写或保存账号信息、原始目录、令牌及完整响应。结果仅代表所测日期、账号、模型和请求条件，不推广为所有模型或后台接口均可用。

## 最小实现

生产代码只将共用 legacy Capabilities 的 web_search 改为 true。浏览器和设备码使用同一能力及 backend 路由；账号选择、授权与刷新、原生工具序列化、事件转换、引用重放、现有三档搜索设置和跨模型 DSH 搜索源全部复用。TypeScript 及 React 生产代码没有改动，既有账号摘要会使两种 legacy 的搜索选项自动开放。没有新增依赖、配置、探测、额外模型调用或自动回退。

额度、生图、连接器和撤销能力保持原值；云端自动压缩继续暂缓。

## 验证

- 35 项 Rust 测试、24 项 Node 测试通过；fmt、全部目标与特性的 Clippy、两套 tsrs 和 Biome 通过。
- 更新现有能力集成测试，覆盖 SIWC 与两种 legacy 反复切换、共享搜索 ready 不触发生成、显式搜索复用单次请求、用户关闭搜索、辅助审批不附带搜索、缺少授权和凭据时不可用，以及 legacy 本地退出。
- 官方 napi-rs release 与绑定生成完成，沿用支持硬链接的临时构建位置；没有修改构建脚本或依赖。宿主与界面生产源码未变，复用既有构建产物。
- 最终原生联调先被工具环境的不可用回环代理阻断。仅在另一个授权测试进程中移除该代理变量后，使用真实 DSH 凭据事务、LLM 服务及搜索提供者验证成功；未修改系统、DSH 或持久环境配置，不把首次网络失败写成成功。
- 当前真实设备码 legacy 账号的 DSH 共享搜索返回非空摘要和 29 个来源，含 Rust 官方来源。普通对话完成内置搜索并持久保留搜索重放项，关闭搜索后多轮续写正常返回前轮来源 URL，确认下一请求没有附带搜索工具。凭据摘要及当前选择未变。浏览器方式共用同一实现，并已通过合成路由验证；本次没有重新进行浏览器授权。
- 独立隐藏浏览器验证 SIWC、legacy 浏览器及设备码的三档选择均可用，实际保存与 display 文案一致；中英文、窄容器及浏览器无错误通过，截图已查看。没有操作用户 DSH 或私人浏览器。

已生成更新包，尚未替换桌面安装；真实桌面搜索交互仍待用户验收。
