# 多语言与登录返回导航验证

编号：EVIDENCE-029。日期：2026-11-07。适用：DSH 0.2.2-rc.1、React 18.3.1。关联：RFC-001、SPEC-001、FACT-002、TODO-001。

## 来源与范围

核对官方发布包 [DSH client locale 0.2.2-rc.1](https://www.npmjs.com/package/@deepseek-ai/dsh-client-locale/v/0.2.2-rc.1) 的声明及实现。其 locale runtime 提供命名空间字典注册、翻译绑定、订阅和语言回退；插槽声明 locale 后由宿主渲染器提供 t，并随语言变更更新组件。

本次复用该官方运行库，不新增第二套翻译运行时或语言偏好。插件声明 locale 客户端依赖，编译期采用官方 Translate 类型；中文和英文资源单独维护，以英文原文作为消息键。设置、插件配置、登录、侧边栏及退出确认使用同一命名空间。原始账号资料不翻译，外部诊断没有对应资源时保留原文。

实际宿主原生模型菜单直接渲染 reasoning effort 的字符串 name，没有提供该字段的翻译上下文；本次保留其既有显示，不通过替换宿主组件扩展改动范围。此次多语言验收针对插件拥有的 React 界面，不能解释为宿主全部菜单均已动态本地化。

## 行为与实现观察

中文将 legacy 标为“过时”，英文保留 legacy；账号行恢复 SIWC，并区分浏览器和设备码方式。登录及偏好 ID 保持不变。其它语言按宿主 locale 库回退到英文。

添加账号的方式面板底栏左侧增加返回按钮：有已有账号时返回账号选择，没有已有账号时回到设置。选定方式后才执行凭据初始化，返回不会写凭据、启动原生授权或打开浏览器；真正授权仍先保存稳定注册身份，再启动原生流程。

提示、错误与选项保留英文源消息，在渲染时翻译；语言切换能更新已经显示的提示和保存错误。条件类名改用现有 cn，静态类名保留直接字符串。账号说明和登录阶段标题采用明确分支，未增加翻译包装框架、全局样式或额外配置。

## 验证结果

- cargo fmt、全部目标和特性的 Clippy、两套 tsrs、Biome 检查通过。Biome 检查 61 个文件；Rust 编译缓存的硬链接不可用时复制提示属于环境信息。没有修改 Rust 源码或重新生成原生发布二进制。
- Tailwind/tsdown 构建通过；产物仍只向浏览器工厂请求宿主 React 依赖。
- 23 项 Node 测试通过。新增验证使用真实官方 LocaleRuntime，检查中英资源键一致、中文语言解析、其它语言英文回退、插值与未识别消息保留；登录测试检查返回不写凭据、不启动授权，既有 SIWC 与 legacy 凭据隔离仍通过。
- 独立无界面浏览器使用最终构建及合成资料，验证中文、英文和法语环境的英文回退；已有提示、保存错误与打开的侧边栏菜单可随语言更新。添加、返回、设备码与取消交互通过，返回位于取消左侧；320 和 480 像素容器无溢出，无浏览器错误，截图已查看。

本次未操作用户浏览器或真实 DSH，未读取私人凭据或发起真实账号授权。更新包安装及真实桌面语言切换验收仍待完成；legacy 完整授权和推理限制沿用 EVIDENCE-027。
