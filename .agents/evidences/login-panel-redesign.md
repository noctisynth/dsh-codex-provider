# 登录区域重设计与官方命名核对

编号：EVIDENCE-028。日期：2026-11-07。适用：DSH 0.2.2-rc.1、当前浏览器构建与 React 18。用户要求增加顶部标志留白、核对 SIWC 命名，并重新整理登录卡片的视觉与交互层级；不改变 EVIDENCE-027 的授权协议与验证边界。

## 官方命名

[官方总入口](https://developers.openai.com/siwc)标题为 Sign in with ChatGPT。SIWC 对应该名称缩写和文档目录命名；不能因此将缩写视为面向用户的登录文案。[开源接入概览](https://developers.openai.com/siwc/token-sharing-open-source)明确把 ChatGPT plan usage 描述为 Sign in with ChatGPT 内的可选能力。Token sharing 出现在集成文档和 SDK 的令牌共享语境中，不是与它并列的另一种登录入口。

[官方 UI/UX 规范](https://developers.openai.com/siwc/ui-ux-guidelines)要求在发起登录时使用 Continue with ChatGPT，并说明使用用户的 ChatGPT 套餐。此次中文界面采用“继续使用 ChatGPT”“使用你的 ChatGPT 套餐”，账号方法标签采用 ChatGPT；内部 siwc 标识及凭据类型不改。Codex 浏览器和设备码继续标明 legacy，不把两种登录路线混称为一个授权协议。

## 实现与视觉职责

保持 OpenAI 图形及侧边栏素材不变，只在设置标题的 48 像素图形外增加 6 像素内边距，形成 60 像素容器，并将标题与按钮垂直居中。

登录区域提取为独立组件，账号选择、登录方式、等待浏览器及设备码采用同一边框、标题及底栏。已有账号选择使用头像、重新登录文案、邮箱与方式，添加新账号移到底栏，与取消明确分开。方式列表使用等规格图标、主次文字及右侧箭头，保留悬停位移和留白。取消保留描边按钮；授权失效的选项列表不再重复展示第二个取消入口。移除用户界面的“注册”术语和 SIWC 缩写。只使用现有 Base UI/shadcn Button 和 Tailwind 样式，无新增界面依赖、全局样式或凭据配置。
