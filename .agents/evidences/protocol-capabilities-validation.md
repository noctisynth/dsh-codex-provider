# 布尔协议能力与业务接入验证

编号：EVIDENCE-035。日期：2026-11-07。适用：DSH 0.2.2-rc.1、Windows x64、当前原生及界面构建。关联：RFC-001、SPEC-001、FACT-002、TODO-001。

## 语义与依据

用户确认采用简单布尔 Capabilities，由业务直接判断，不把支持依据、待验证、未实现和暂缓状态放进运行时状态机。true 表示当前插件为该登录路线开放此项能力；false 只表示不开放，不能解释为服务端永久不支持。账号授权、模型元数据和用户偏好仍分别判断。

依据：[SIWC 公开限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)、EVIDENCE-005、EVIDENCE-022、EVIDENCE-027、EVIDENCE-032、当前模块化认证和请求实现。SIWC 内置搜索有真实完成证据，legacy 目前接入的 Responses 路径尚无该内置工具的成功证据；社区专用搜索是另一条接口，不能用其存在开放本插件当前路径。SIWC 已有远端撤销实现，legacy 的退出语义为本地清除。没有进行新的凭据或接口探测。

| 字段 | SIWC | legacy 浏览器与设备码 | 开放依据及边界 |
|---|---|---|---|
| web_search | true | false | 本插件当前 Responses 内置搜索；legacy 专用搜索尚未接入，不能解释为所有 legacy 搜索不可用 |
| quota | false | false | 当前插件没有额度查询功能；legacy 后台权限仍须按目标接口验证 |
| image_generation | false | false | SIWC 明确受限，legacy 生图未接入；不注册额外工具 |
| connectors | false | false | SIWC 托管连接器受限，legacy 连接器未接入；DSH 本地 MCP 不属于此能力 |
| remote_revocation | true | false | 现有 SIWC 远端撤销与 legacy 本地退出语义 |

普通对话、工具、图片和推理档位沿用现有模型目录与请求适配，不重复增加布尔模型元数据。云端压缩继续暂缓，不因已有协议实验而增加开关或请求字段。

## 最小实现

Rust 使用一个 Capabilities 结构体和登录方式对应的定义。浏览器、设备码匹配同一个 legacy 分支；不依赖型号猜测、配置或自动探测。napi-rs 生成绑定类型，账号摘要携带纯布尔对象，TypeScript 与 React 复用生成类型；没有凭据格式变更、持久能力缓存或新配置。

原生流入口在联网前检查内置搜索能力。宿主普通对话结合用户开关决定是否附带搜索；legacy 即使保留旧搜索偏好，也可以正常发普通对话。显式独立搜索不可用时报错，共享搜索源的 ready 同时核对当前账号、授权及能力。账号切换后重新读取摘要，不沿用前一账号的能力。

设置页消费活动账号能力，legacy 下保留现有偏好显示，禁用两个启用搜索的选项，仍允许选择关闭；不删除用户选择或增加新保存门禁。提供中英文的当前不可用说明。远端撤销和 localOnly 结果使用同一能力定义，行为保持原有契约。
