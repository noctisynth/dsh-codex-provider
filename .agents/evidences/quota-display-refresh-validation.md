# 额度展示与共享刷新验证

编号：EVIDENCE-038。日期：2026-11-08。版本：插件开发工作区；DSH 0.2.2-rc.1。关联：RFC-001、SPEC-001、FACT-002、EVIDENCE-037。

## 套餐代码与产品名称

- 真实只读实验：使用现有有效 legacy 授权请求额度接口，HTTP 200，仅提取 plan_type；返回代码 prolite，查询前后凭据字节一致。未输出或记录令牌、账号标识、完整响应或余额。
- 官方说明：OpenAI Pricing 页面将 100、200、500 美元三档归在 Pro 下。来源：https://learn.chatgpt.com/docs/pricing?codex-pricing-plans=individual 。该说明支持统一产品名称，不能证明各档实际返回的全部内部代码。
- 实现决策：只在界面将 pro 系列代码显示为 Pro，保持 Rust 原始字段、服务端额度及窗口不变。不根据产品名称推算额度或价格，也未实测另两档套餐。

## 实现与离线集成

- 设置卡片保留原布局；进度条由 4px 调整为 8px，圆角消费 DSH radius token；重置时间从服务端时间戳呈现为天/小时、小时/分钟、分钟倒计时，按分钟更新，不展示负数。
- 侧边栏有 quota 能力的已登录账号，在原有第二行展示 Codex 窗口剩余比例；保留 44px 行高、24px 头像，折叠时由提示展示。SIWC 不订阅额度；查询失败不继续展示旧比例。
- 新增统一额度刷新 Select，默认 5 分钟，支持关闭、1、5、15 分钟，说明仅过时登录方式展示；账号菜单与设置卡片均可手动刷新。设置持久化沿用正式宿主配置接口，重启恢复已验证。
- 同一连接和账号共享结果、在途查询及定时器。设置和侧边栏并存不产生第二次初始请求，手动刷新同步更新；页面隐藏时不轮询，返回时在启用自动刷新的情况下查询；关闭自动刷新后保留首次读取和手动刷新。
- 最后一个消费者卸载取消请求并清理定时器、可见性监听及额度；迟到结果不会恢复已卸载账号数据。新账号独立存储，切到 SIWC 不再展示旧额度。未修改认证、原生协议及已暂缓的云端压缩。
- Node 共 29 项测试通过，新增真实宿主 locale 的倒计时及共享轮询、关闭、隐藏、去重、失败和取消验证；已有构建包交互测试验证双入口共享、SIWC 隐藏和错误更新。Rust fmt、全部目标及特性的 Clippy、两侧 tsrs、Biome 均通过。Clippy 仅有现有文件系统硬链接转复制警告；构建保留既有第三方 use client 和依赖打包提示。

## 独立浏览器验证

使用真实构建产物及正式 DSH locale 运行时，合成账号和额度，通过独立无头浏览器检查浅色、深色、320px 窄容器及折叠侧栏。确认进度条实测 8px、卡片圆角跟随 8px 宿主 token、侧边栏行高 44px；显示 Pro 与相对重置时间。设置和侧栏手动刷新、Select 保存间隔、中英文切换均通过，无页面错误或横向溢出，截图已人工查看。该验证不替代实际 DSH 安装后的桌面交互验收。
