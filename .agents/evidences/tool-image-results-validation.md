# 工具图片结果续接修复验证

编号：EVIDENCE-047。日期：2026-11-12。范围：DSH 0.2.2-rc.1、当前 Responses 适配、本机 macOS arm64 构建与离线验证。

## 观察与实现

用户截图报告工具读图后出现 INVALID_REQUEST。源码与新增回归分别确认：TS 附件投影主动拒绝非用户消息中的图片；Rust 工具结果转换仅拼接文本，丢弃图片。未读取原始故障会话或运行日志，截图中的具体调用仅按时序推断，不作为已复现的私人会话记录保存。

最小修复只在原有 TS 图片角色判断中允许 tool；Rust 仅将含图片的工具结果转换为同一 function_call_output 的图文数组。保留 call_id、内容顺序和现有图片精度；纯文本和空工具结果保持原字符串格式。沿用附件读取、offloaded、文字模型投影及取消，不改历史、不伪装用户消息、不新增依赖、配置、重试或通用抽象。官方协议声明与限制由 FACT-002 维护。

## 验证结果

- 修改生产实现前，DSH 回归因工具图片导致错误完成而失败；Rust 回归确认原工具结果仅剩文本字符串，缺少两张图片。修复后两者通过。
- Rust 回归覆盖同一调用内文字与两图交错顺序、后续 assistant/user 历史、仅图片结果、全部四档图片精度、缺失或空图片 URL 的现有校验，以及空、单段和多段纯文本工具结果的字符串兼容。
- 正式 DSH LlmRuntime 与 ChatGptAdapter 集成覆盖用户及工具消息：视觉模型读取四张保留图片；offloaded 只保留文字占位；文字模型不读取附件；toolCallId 与图文顺序保持不变。取消、读取失败及原始不可变历史回归继续通过。附件字节与原生响应流使用合成替身，此项不等同真实服务端请求。
- Rust 全量 49 项测试、fmt 及全部目标与 feature 的 Clippy 严格检查通过。
- 官方 napi-rs 本机 release 构建、Tailwind/tsdown 构建、两侧 Oxc tsrs 类型检查及变更 TypeScript 的 Biome 检查通过。JS 构建仍有第三方 use client 指令及依赖打包提示，未据此修改无关界面。
- Node 22.20.0 加载重建产物，全量 33 项测试通过，包含本机打包根目录及官方平台包回退加载。
- 验证环境差异：最初使用宿主附带的 Node 24.21.0 加载本地原生库被 macOS Team ID 限制拒绝；改用本机既有 Node 22.20.0 验证，未修改签名或系统安全设置。napi-rs 父目录 staging 与 npm 标准缓存写入最初被沙箱阻止，获批重跑原命令后成功，未更改权限或构建机制。
