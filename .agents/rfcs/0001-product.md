# 产品需求与边界

编号：RFC-001。状态：已确认约束，功能范围待细化。更新：2026-11-06。

## 目标

构建新的 DSH ChatGPT 接入插件，Rust 实现核心能力，少量 JS 适配宿主，使用 napi-rs 原生绑定，遵循最新 ChatGPT 官方公开接入协议。交付目标为生产可用；功能缺失、未实现或关键集成未验证均属于开发状态。

## 已确认约束

- 保持满足需求的最小实现，避免附加功能、配置、抽象和推测性防御。
- Rust 模块职责清晰，优先社区成熟依赖，限制 panic 与 unsafe。
- 采用 napi-rs 官方构建体系与 Semifold 版本发布管理。
- 先完善需求和技术方案，再更新实施待办；当前仅建立上下文，不开展产品编码。

## 待确定的功能契约

登录、账号资料保存、令牌刷新与退出、模型发现、流式对话、工具调用和取消是拟议的核心能力，需要结合 DSH 宿主契约明确验收行为。账号数量、平台支持矩阵、代理需求、已有登录迁移和额度展示尚未定案，不默认承诺，也不默认排除。

图片、搜索、连接器、远程控制等附加能力尚无实施授权。不能因参考产品提供这些功能就复制进需求。

## 交付判断

生产交付需要已确认范围内的功能、安装构建、宿主集成及官方授权请求路径均成立。用实际验证说明支持的组合；不得将缩减功能后的可运行演示描述为交付完成。
