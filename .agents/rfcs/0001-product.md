# 产品需求与边界

编号：RFC-001。状态：已确认约束，功能范围待细化。更新：2026-11-06。

## 目标

构建新的 DSH ChatGPT 接入插件，Rust 实现核心能力，少量 JS 适配宿主，使用 napi-rs 原生绑定，遵循最新 ChatGPT 官方公开接入协议。交付目标为生产可用；功能缺失、未实现或关键集成未验证均属于开发状态。

## 已确认约束

- 保持满足需求的最小实现，避免附加功能、配置、抽象和推测性防御。
- Rust 模块职责清晰，优先社区成熟依赖，限制 panic 与 unsafe。
- 采用 napi-rs 官方构建体系与 Semifold 版本发布管理。
- 手写适配使用 TypeScript，采用 tsdown 与 Oxc tsrs 的 Rust 工具链；napi-rs 生成代码保持官方产物。
- 先完善需求和技术方案，再更新实施待办；已授权开发，并在每项可独立验收成果完成后记录变更集和本地提交。

## 待确定的功能契约

登录、账号资料保存、令牌刷新与退出、模型发现、流式对话、工具调用和取消是拟议的核心能力，需要结合 DSH 宿主契约明确验收行为。官方账号注册管理约束参见 FACT-002；账号交互、平台支持矩阵、代理需求、已有登录迁移和额度展示尚未定案，不默认承诺，也不默认排除。

图片、搜索、连接器、远程控制等附加能力尚无实施授权。不能因参考产品提供这些功能就复制进需求。

## 交付判断

登录、账号管理与模型选择融入 DSH 的设置及正常模型选择流程，参考既有社区插件的宿主界面接入方式。不以专用斜杠命令替代用户入口。

模型切换应稳定完成，不能因重复目录请求与刷新竞态而失败；多轮对话及工具结果必须保留有效的协议上下文。

模型元数据应提供官方目录声明的上下文容量，供 DSH 执行上下文压缩与模型切换；不从型号猜测或使用未启用的最大扩展窗口。请求失败时展示公开接口返回的具体错误说明，避免仅有 HTTP 状态码而无法判断原因。

通过 DSH 正常模型选择流程调整当前模型支持的 reasoning effort，采用官方目录提供的档位和默认值，并将选择传入推理请求。选择器展示可读名称，参考 Codex 简体中文文案；显示名称与请求使用的原始档位 ID 分离。

重新设计插件设置入口，结合 DSH 视觉体系与 Codex 的简洁交互风格；优先采用 shadcn/ui 与 Tailwind CSS，尽量不编写全局或非 Tailwind 样式。覆盖既有登录与账号管理流程，不扩展附加业务功能。

账号界面采用紧凑列表，隐藏注册标识等内部资料；添加账号使用小尺寸按钮，退出登录使用红色按钮并在弹窗确认后执行。切回界面应读取最新状态，操作反馈不永久驻留；已退出账号不能标为当前使用，并提供重新登录入口。

标题左侧保留图标区域，使用 OpenAI 官方 Blossom 标志；设置侧边栏的 ChatGPT 项使用相同标志。

用户可在 ChatGPT 设置页选择左下角显示 DeepSeek 或 ChatGPT 账号，保存选择并允许随时恢复 DeepSeek。ChatGPT 模式显示当前已登录账号的头像和姓名，点击打开账号弹出菜单，提供设置、恢复 DeepSeek 和退出登录；退出仍需确认。用户已接受整个账号组件被替换的边界：ChatGPT 模式不显示原 DeepSeek 账号菜单及其登录、额度提醒；恢复 DeepSeek 后使用原组件。

侧边栏入口的尺寸和视觉密度贴近 DSH 原入口与 Codex，不增加独立卡片式外壳或额外设置图标；设置中的展示切换控件保持紧凑。

账号行参考 Codex，展示官方身份提供的头像、姓名及次要信息。没有可靠套餐字段时使用邮箱；不推测套餐。头像优先使用 OpenAI 返回的图片，缺失或加载失败时尝试邮箱对应的 Gravatar；仍无可用图片时以姓名或邮箱首字作为最终文字占位。

登录选择使用轻量列表，已有账号明确标注“重新登录”，新账号入口标注“添加新账号”。等待选择时不显示加载动画；选项箭头随整行悬停轻微右移，移动后仍保留清晰的右侧留白，并遵循系统减少动态效果偏好。

登录操作区保留轻量容器边界和留白，使其与已有账号及下方模型说明清晰分区；选项保持简洁行布局，避免失去层级或出现多层卡片叠加。

取消登录应有明确的按钮外观，与账号选择操作分区，在选择账号和等待浏览器授权时均容易找到。

已授权备份当前 DSH 的 Codex 凭据及回滚材料，移除旧插件、安装本项目本地产物并开展桌面宿主实测。替换以新包能够被宿主加载为前提；凭据备份保存在用户数据区域，不进入项目上下文或 Git。当前实测对象为 Windows x64 桌面宿主。

生产交付需要已确认范围内的功能、安装构建、宿主集成及官方授权请求路径均成立。用实际验证说明支持的组合；不得将缩减功能后的可运行演示描述为交付完成。
