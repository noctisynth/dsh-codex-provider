# 产品需求与边界

编号：RFC-001。状态：已确认约束，功能范围待细化。更新：2026-11-07。

## 目标

构建新的 DSH ChatGPT 接入插件，Rust 实现核心能力，少量 JS 适配宿主，使用 napi-rs 原生绑定，遵循最新 ChatGPT 官方公开接入协议。交付目标为生产可用；功能缺失、未实现或关键集成未验证均属于开发状态。

## 已确认约束

- 保持满足需求的最小实现，避免附加功能、配置、抽象和推测性防御。
- Rust 模块职责清晰，优先社区成熟依赖，限制 panic 与 unsafe。
- 采用 napi-rs 官方构建体系与 Semifold 版本发布管理。
- 手写适配使用 TypeScript，采用 tsdown 与 Oxc tsrs 的 Rust 工具链；napi-rs 生成代码保持官方产物。
- 先完善需求和技术方案，再更新实施待办；已授权开发，并在每项可独立验收成果完成后记录变更集和本地提交。

## 待确定的功能契约

登录、账号资料保存、令牌刷新与退出、模型发现、流式对话、工具调用和取消已纳入核心能力，具体验收状态由 TODO-001 维护。官方账号注册管理约束参见 FACT-002；超出现有账号操作的附加交互、平台支持矩阵、代理需求、已有登录迁移仍待定，不默认承诺，也不默认排除。

用户要求下一步对齐社区插件的额度展示等能力；当前明确目标为套餐用量的可见性，先确认 SIWC 可用数据源。剩余比例、窗口与重置时间以官方返回为依据，不能用本地 token 计数推算。其他附加能力逐项确定，不将“等能力”解释为整体复制社区功能。

用户已授权原生图片输入：通过 DSH 正常附件流程向支持图片的模型发送图片，保留多图顺序及多轮上下文。搜索授权由下述新增需求确定；连接器、远程控制等附加能力尚无实施授权。不能因参考产品提供这些功能就复制进需求。

用户进一步授权先以现有 SIWC 凭据和合成资料实测原生文件输入及图片精度选择，确认实际可用后接入插件。文件沿用 DSH 附件流程，图片精度提供受支持的选择并保留自动默认值；遵守宿主权限和持久历史，不通过解析文字占位或修改宿主绕过文件投影。若宿主接口无法正确承载，说明障碍并询问方案。保持模块化和最小实现，Codex 独立子任务暂不实施。完成后确认 SIWC 的云端压缩、切档缓存复用可行性；该项仅授权调研验证，不自动加入实现。

核对当前宿主文件投影限制后，用户明确选择：原生文件暂记宿主阻塞，继续接入图片精度；不实施请求拦截方案。

用户随后授权实测图片生成与订阅搜索的可用性，要求确认后答复；该授权用于能力验证，不自动纳入功能实施。实测依据 EVIDENCE-022。

用户希望独立选择自动审查模型：在启用 DSH 官方实验自动审查组件后，可保留“会话模型”审查，也可选择“Codex”审查，使 DeepSeek、MiniMax 等会话使用当前 ChatGPT 账号的专用审查模型。要求尽可能接近 Codex 行为，当前先完成可行性检查；模型路由、策略、触发范围与沙箱语义分别说明，不能以使用同一模型代表权限机制完全一致。依据 EVIDENCE-023。

用户进一步要求保留沙箱，仅在原有工具流程需要审批时才进行模型审查。该目标优先于套用实验 Auto preset：不得为了自动审查把整个会话改为完全权限。保留人工审批路径；新增 ChatGPT 模式决定单次审批，原权限禁止且不允许申请的操作仍保持禁止。DSH 原实验 Auto 的会话模型模式继续使用宿主入口。审批接口的后续核对见 EVIDENCE-023。

用户已授权实施保留沙箱的 ChatGPT 独立审批模式，以及官方 web_search，默认关闭。关闭审批模式恢复人工审批，开启时只接管必要审批；不改变会话权限，未能确定准确操作或服务不可用时不得自动放行。网页搜索通过公开 Responses 实现，提供关闭、仅 ChatGPT、所有模型三档；所有模型模式使用共享 DSH 搜索源，离开该模式恢复原来源。其它模型搜索额外使用 ChatGPT 账号用量。并修复设置页及账号菜单中切回 DeepSeek 显示的保存失败。用户已确认关闭 DSH，完成全部修复验证后直接更新安装。

账号显示、ChatGPT 审批和网页搜索采用统一的 DSH 设置行结构：左侧标题与说明，右侧选择或开关；不混用三种独立按钮组设计。配置文件被编辑器占用导致保存失败时应给出可操作的提示，保留宿主原子保存机制。

设置项的次要说明面向用户，只陈述行为、结果和用量归属，不展示内部实现或防御性推理。明确告知官方 Auto 使用会话模型审查，不会叠加本插件的 ChatGPT 审查调用。

账号显示与搜索范围使用 Select 选择组件；必须在 DSH 设置弹窗和插件配置弹窗内正常展开、选择并恢复焦点，不使用操作菜单替代选择控件。

Select 收起时显示与选项一致的用户文案，初次加载和切换后均不能显示内部配置值。

同时支持 SIWC、Codex 浏览器 legacy 与 Codex 设备码 legacy 登录。前端复用账号及授权交互，根据用户选择交由原生核心执行对应流程；SIWC 与 legacy 可以同时保留有效凭据，在同一账号列表中切换当前使用路线。同一主体及工作区的两种 legacy 登录更新同一记录，最近成功的登录方式用于展示；不影响 SIWC 凭据。账号行展示低强调的登录方式标签；设备码流程展示验证地址与一次性用户码，可取消并自动更新完成状态。保留现有 SIWC 登录，不静默改换路线，不导入或共享外部客户端的凭据文件。额度、Fast、生图等附加能力不自动纳入本次需求。

顶部标志保留原图形并增加容器留白。登录区域统一账号选择、方式选择、等待授权和设备码的视觉层级，明确区分列表与底部操作；取消保持清晰可见。使用面向用户的账号及套餐文案，不展示“注册”等内部术语；方式标签保留 SIWC，并明确标识过时的 Codex 方式，方便辨别重复账号。官方命名依据记录在事实与证据中。

界面支持中文和英文，遵循 DSH 语言设置；非中文语言缺少翻译时回退英文。中文将 legacy 显示为“过时”。添加新账号的方式选择页在底栏左侧提供返回入口，可回到已有账号选择；没有已有账号时返回账号设置，不启动原生登录或修改凭据。React 侧直接复用成熟的 i18n 库能力，条件样式优先使用 cn，保持组件职责清楚，不自建翻译、回退或语言持久化框架。

工程治理覆盖 Rust 与 TypeScript 的可读性、维护性和职责封装，不增加产品功能。Rust 通过 fmt 和全部目标 Clippy；TypeScript 通过 tsrs 与 Biome，采用单引号、2 空格缩进并启用 Tailwind 支持。评估并采用兼容现有宿主的 Base UI 简化交互依赖；UI 组件许可与组件共同维护并随包分发。全部治理及必要集成验证完成后统一生成变更集并本地提交，不提前分段提交。

用户曾提出通过会话权限菜单独立选择 ChatGPT 审批。核对宿主动态注册限制与官方 Auto 的完全权限、全量审查语义后，用户决定暂时保持现状：保留现有插件审批开关及必要审批边界，不新增会话控件、不修改 DSH 源码、不接管官方 Auto。后续改造不视为已确认实施需求，依据 EVIDENCE-024。

## 交付判断

登录、账号管理与模型选择融入 DSH 的设置及正常模型选择流程，参考既有社区插件的宿主界面接入方式。不以专用斜杠命令替代用户入口。

模型切换应稳定完成，不能因重复目录请求与刷新竞态而失败；多轮对话及工具结果必须保留有效的协议上下文。

模型元数据应提供官方目录声明的上下文容量，供 DSH 执行上下文压缩与模型切换；不从型号猜测或使用未启用的最大扩展窗口。请求失败时展示公开接口返回的具体错误说明，避免仅有 HTTP 状态码而无法判断原因。

核心对话契约包含宿主实际触发的摘要压缩请求和上下文超限恢复；不得发送当前 SIWC 不支持的参数。认证、额度和上下文错误应保留宿主可识别的分类与公开诊断信息。终止刷新失效时停止使用失效令牌，并能通过已保存的注册重新授权；临时网络失败不得清除凭据。

用户已授权修复上述三项核心问题，并完成必要集成验证后统一生成变更集与本地提交。验收覆盖真实宿主压缩入口、原生错误到宿主恢复分类、失效令牌清理的事务持久化与重新授权入口；不通过制造真实账号失效来验收。此次不加入 Fast 或其他社区扩展功能。

只提供当前插件能够完整执行的推理档位。用户已确认移除不可用的 Ultra，保留 Max 等普通档位；不静默降档，不在此次修复中新增主动多 Agent 能力。

通过 DSH 正常模型选择流程调整当前模型支持的 reasoning effort，采用官方目录提供的档位和默认值，并将选择传入推理请求。选择器展示可读名称，参考 Codex 简体中文文案；显示名称与请求使用的原始档位 ID 分离。

用户要求先验证当前 SIWC 授权的 Fast 能力，再为插件加入 Fast 开关。Fast 独立于推理强度；按官方公开契约、账号目录和适用于当前路由的验证判断，不只凭 HTTP 成功或无法确认语义的单一响应字段承诺加速。若公开协议的实际行为不能满足该目标，先说明限制并询问用户，不添加只有界面状态而没有实际效果的开关。

重新设计插件设置入口，结合 DSH 视觉体系与 Codex 的简洁交互风格；优先采用 shadcn/ui 与 Tailwind CSS，尽量不编写全局或非 Tailwind 样式。覆盖既有登录与账号管理流程，不扩展附加业务功能。

账号界面采用紧凑列表，隐藏注册标识等内部资料；添加账号使用小尺寸按钮，退出登录使用红色按钮并在弹窗确认后执行。切回界面应读取最新状态，操作反馈不永久驻留；已退出账号不能标为当前使用，并提供重新登录入口。

标题左侧保留图标区域，使用 OpenAI 官方 Blossom 标志；设置侧边栏的 ChatGPT 项使用相同标志。

标志的实际可见尺寸应与 DSH 同组图标协调，不将官方素材的整幅留白计入图标尺寸。

用户可在 ChatGPT 设置页选择左下角显示 DeepSeek 或 ChatGPT 账号，保存选择并允许随时恢复 DeepSeek。ChatGPT 模式显示当前已登录账号的头像和姓名，点击打开账号弹出菜单，提供设置、恢复 DeepSeek 和退出登录；退出仍需确认。用户已接受整个账号组件被替换的边界：ChatGPT 模式不显示原 DeepSeek 账号菜单及其登录、额度提醒；恢复 DeepSeek 后使用原组件。

侧边栏入口的尺寸和视觉密度贴近 DSH 原入口与 Codex，不增加独立卡片式外壳或额外设置图标；设置中的展示切换控件保持紧凑。

账号行参考 Codex，展示官方身份提供的头像、姓名及次要信息。没有可靠套餐字段时使用邮箱；不推测套餐。头像优先使用 OpenAI 返回的图片，缺失或加载失败时尝试邮箱对应的 Gravatar；仍无可用图片时以姓名或邮箱首字作为最终文字占位。

登录选择使用轻量列表，已有账号明确标注“重新登录”，新账号入口标注“添加新账号”。等待选择时不显示加载动画；选项箭头随整行悬停轻微右移，移动后仍保留清晰的右侧留白，并遵循系统减少动态效果偏好。

登录操作区保留轻量容器边界和留白，使其与已有账号及下方模型说明清晰分区；选项保持简洁行布局，避免失去层级或出现多层卡片叠加。

取消登录应有明确的按钮外观，与账号选择操作分区，在选择账号和等待浏览器授权时均容易找到。

已授权备份当前 DSH 的 Codex 凭据及回滚材料，移除旧插件、安装本项目本地产物并开展桌面宿主实测。替换以新包能够被宿主加载为前提；凭据备份保存在用户数据区域，不进入项目上下文或 Git。当前实测对象为 Windows x64 桌面宿主。

生产交付需要已确认范围内的功能、安装构建、宿主集成及官方授权请求路径均成立。用实际验证说明支持的组合；不得将缩减功能后的可运行演示描述为交付完成。
