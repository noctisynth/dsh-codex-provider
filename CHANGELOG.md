## v0.1.0

### Bug Fixes

- [`06f9c84`](https://github.com/noctisynth/dsh-codex-provider/commit/06f9c84607044e989ff3cbcaf8568388f0148b24): Send an explicit null payload for parameterless account RPC calls so DSH's required envelope field survives JSON serialization. Fix login HTTP 400 and verify the shipped React component's login and cancellation requests against the official host schema.
- [`4789d5a`](https://github.com/noctisynth/dsh-codex-provider/commit/4789d5a2829cf1ed57a65d37a90378d37002e351): Refresh account status explicitly after operations and when returning to the window. Stop replaying stale success notices and marking signed-out accounts as active. Replace account cards with compact rows, hide registration identifiers, use smaller add-account buttons, and require modal confirmation before logout.
- [`d08ab08`](https://github.com/noctisynth/dsh-codex-provider/commit/d08ab089b0fb1fc652b2fa8aae12b9348084a3b3): Reuse the active account's model catalog and concurrent catalog request until credentials change. Preserve streamed output items when the completion event has an empty output array, and retain visible content from previously saved empty replay snapshots. Fix missing tool-call context in later requests; validate native tool-result continuation and subsequent conversation against the public endpoint.
- [`64e0d0e`](https://github.com/noctisynth/dsh-codex-provider/commit/64e0d0ea350651c4de61d3fc0e6a7b24a2b62682): Send a stable request-scoped session-id header for Codex browser and device sign-in so ChatGPT Responses can use session cache affinity. Preserve the existing prompt_cache_key and leave SIWC and requests without a session ID unchanged.
- [`b72f793`](https://github.com/noctisynth/dsh-codex-provider/commit/b72f79338ae2216a8842a936dd133f3a14079df6): Use Codex 0.167.0 for the direct-login model catalog's client_version instead of the internal crate version. Restore GPT-6.1 Sol and GPT-6.1 Terra discovery while keeping the existing dynamic catalog and SIWC route.
- [`93017e8`](https://github.com/noctisynth/dsh-codex-provider/commit/93017e822d954b28b38639e7da8373358d919bfc): Fix compaction requests by omitting parameters unsupported by Sign in with ChatGPT. Preserve public provider error details and map failures to DSH classifications so context overflow can trigger host recovery. Persist cleared tokens after terminal refresh failures before prompting for sign-in, while retaining the account registration and credentials on temporary failures.
- [`0ba9124`](https://github.com/noctisynth/dsh-codex-provider/commit/0ba91242f1a73e69d9d94364aea59fc4ab6a4992): Align host peer dependencies with the installed DSH 0.2.2-rc.1 runtime and Cordis 4.1. Validate registration with those official packages and install the local Windows build through the desktop CLI without a compatibility exemption.
- [`b0c0827`](https://github.com/noctisynth/dsh-codex-provider/commit/b0c0827ea6bdad29271a458c6a0035e152265455): Exclude Codex Ultra from the provider's reasoning capabilities because it requires multi-agent orchestration and is not a valid Responses effort. Keep the model's other supported efforts, including Max, without silently changing saved selections.
- [`ce04c37`](https://github.com/noctisynth/dsh-codex-provider/commit/ce04c3769a6d1de80b096407b10c02716693bfd0): Preserve conversation prefixes when application instructions and tools change. Use advertised Codex incremental-model metadata rather than a model-name whitelist, expose system and native tool updates separately, append scoped developer instructions and additional_tools in history, and retain valid reasoning-effort checkpoints. Keep SIWC, auxiliary calls, and models without advertised support on the existing projection.
- [`ee3738a`](https://github.com/noctisynth/dsh-codex-provider/commit/ee3738a54041d7376fc298303c70c16922c80519): Make login cancellation easier to find with a small outlined button in a separate footer below account choices and browser authorization status.
